# Konark Agarwal — Portfolio

A static, responsive portfolio website. Open `index.html` locally to preview it, or deploy the site files to a static hosting provider.

## What’s included
- `index.html` — portfolio homepage and selected projects
- `about.html`, `contact.html` — standalone pages retained from the supplied site
- `projects.html` — forwards to the selected-work section on the homepage
- `css/style.css`, `js/script.js` — styles and interactions
- `assets/images/` — project preview images and profile photos

## Preview
Open `index.html` in a browser. Google Fonts and Font Awesome are loaded from external CDNs, so those assets need an internet connection; the local HTML/CSS/JS and image files are included.

## Deployment
Upload the contents of this folder to your static hosting project.
